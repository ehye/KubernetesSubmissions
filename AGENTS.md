# Repository Guidelines

This is a repo for kubernetes exercise

## Implementation

For learning purpose, the user may / should write k8s config not in the best practice, instead of fix it right away, provide learning material, don't introduce too many new concept for user

## Commit & Pull Request Guidelines

- Before create a pull request, udpate the root README, add a url link which points to its next release version and folder path, then include this change into latest commit rather than a individual commit
- Use tag for release title, e.g, 1.1
- Release notes only need one line of text, simply mention what has add/update which can refer to feat commit
